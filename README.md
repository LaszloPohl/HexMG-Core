# HexMG-Core

This is the `codex/optimized-solver` development branch. The user-maintained
baseline remains on `main`. OPTIONAL blocks can now be skipped anywhere in
HMG, up to the first end marker in the same file. LEVEL0 precision selection
is implemented with extended-reference validation; speedup is not claimed.
See [precision scope and tests](doc/LEVEL0_PRECISION_HU.md). The variants will remain
separate; no future merge into the baseline is planned.
See [branch scope and compatibility](doc/OPTIMIZED_VARIANT_HU.md).

- [Manual OPTIONAL skip code for the baseline](doc/OPTIONAL_SKIP_BASELINE_HU.md)
- [Living optimization and repair backlog](doc/OPTIMIZATION_BACKLOG_HU.md)

This project is in basic form. More details will be added later.
